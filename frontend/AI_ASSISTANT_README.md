# AI 智能助手使用指南

## 📖 简介

AI 智能助手是一个基于 LangChain4j 的图形化交互界面，提供三大核心功能：

- 💬 **智能对话** - 自然语言聊天问答
- 🗄️ **SQL优化** - 智能分析和优化SQL语句
- 💻 **代码生成** - 根据描述自动生成代码

## 🚀 快速开始

### 前置要求

1. ✅ 后端服务已启动（端口 8091）
2. ✅ 现代浏览器（Chrome、Firefox、Edge、Safari）

### 启动方式

#### 方式一：使用启动脚本（推荐）

**Windows：**

```bash
cd frontend
start-ai.bat
```

**macOS/Linux：**

```bash
cd frontend
./start-ai.sh
```

#### 方式二：直接打开

直接在浏览器中打开文件：

```
frontend/ai-assistant.html
```

## 📋 功能说明

### 1. 💬 智能对话

**功能特点：**

- 支持多轮对话，记住上下文
- Markdown 格式渲染
- 实时消息显示
- 快捷键发送（Ctrl + Enter）

**使用方法：**

1. 在输入框中输入问题
2. 点击"发送"按钮或按 Ctrl + Enter
3. 等待 AI 回复

**示例问题：**

```
- 什么是微服务架构？
- Java 和 Python 有什么区别？
- 如何优化数据库查询性能？
- 解释一下设计模式中的单例模式
```

### 2. 🗄️ SQL优化

**功能特点：**

- 左右对比显示（原始SQL vs 优化后SQL）
- 实时语法高亮
- 优化建议提示

**使用方法：**

1. 在左侧"原始 SQL"面板中输入需要优化的SQL
2. 点击"优化SQL"按钮
3. 查看右侧优化结果

**示例SQL：**

```sql
-- 优化前
select * from user where age > 18 and name like '%admin%'

-- 优化后（建议）
SELECT id, username, email FROM user 
WHERE age > 18 AND username LIKE '%admin%'
LIMIT 100
```

**注意事项：**

- 当前版本建议使用 `/smart-sql/optimize` 接口进行更专业的SQL优化
- 避免使用 `SELECT *`，明确指定字段
- 添加必要的 `LIMIT` 限制

### 3. 💻 代码生成

**功能特点：**

- 自然语言描述需求
- 自动生成完整代码
- 一键复制功能

**使用方法：**

1. 在输入框中描述代码需求
2. 点击"生成代码"按钮
3. 查看生成的代码
4. 点击"复制"按钮复制到剪贴板

**示例需求：**

```
- 创建一个用户管理的Spring Boot Controller，包含增删改查接口
- 写一个Java方法，实现快速排序算法
- 生成一个Python脚本，读取CSV文件并统计每列的平均值
- 创建一个Vue组件，显示用户列表并支持分页
```

## 🔧 配置说明

### API 地址配置

如果需要修改后端API地址，编辑 `ai-assistant.html` 文件：

```javascript
// 第 534 行
const API_BASE = 'http://localhost:8091/ai';
```

修改为你的实际地址：

```javascript
const API_BASE = 'http://your-server:port/ai';
```

### 后端接口

| 功能    | 接口路径               | 方法  | 参数           |
|-------|--------------------|-----|--------------|
| 智能对话  | `/ai/chat`         | GET | `msg`: 问题文本  |

| 代码生成  | `/ai/code/gen`     | GET | `req`: 需求描述  |

## 💡 使用技巧

### 智能对话技巧

1. **清晰表达**：问题越具体，回答越准确
   ```
   ❌ "Java是什么？"
   ✅ "请简要介绍Java的主要特性和应用场景"
   ```

2. **分步提问**：复杂问题分解为多个小问题
   ```
   第一步："什么是RESTful API？"
   第二步："如何用Spring Boot实现RESTful API？"
   第三步："能给我一个完整的示例代码吗？"
   ```

3. **提供上下文**：必要时提供背景信息
   ```
   "我正在开发一个电商系统，需要设计订单表，
   应该包含哪些字段？"
   ```

### SQL优化技巧

1. **提供完整SQL**：包括所有子句
   ```sql
   SELECT u.name, COUNT(o.id) as order_count
   FROM users u
   LEFT JOIN orders o ON u.id = o.user_id
   WHERE u.status = 1
   GROUP BY u.name
   ORDER BY order_count DESC
   LIMIT 10;
   ```

2. **说明业务场景**：帮助AI理解优化方向
   ```
   -- 这是一个高频查询，需要考虑性能
   SELECT * FROM products WHERE category_id = 1
   ```

### 代码生成技巧

1. **详细描述**：包含技术栈、功能要求、约束条件
   ```
   创建一个Spring Boot Controller：
   - 技术栈：Spring Boot 2.7 + MyBatis Plus
   - 功能：用户管理的CRUD
   - 要求：包含参数验证、统一返回格式、异常处理
   - 接口：GET /users, POST /users, PUT /users/{id}, DELETE /users/{id}
   ```

2. **指定代码风格**：说明编码规范
   ```
   生成Java代码，遵循以下规范：
   - 使用 Lombok 简化代码
   - 使用 SLF4J 记录日志
   - 添加完整的 Javadoc 注释
   ```

## ⚠️ 注意事项

1. **网络连接**：确保后端服务正常运行
2. **浏览器兼容**：推荐使用最新版本的 Chrome 或 Firefox
3. **响应时间**：复杂请求可能需要几秒到几十秒
4. **结果验证**：AI生成的内容需要人工审核和测试

## 🐛 常见问题

### Q1: 页面无法加载或显示空白？

**A:**

- 检查浏览器控制台是否有错误
- 确认 `ai-assistant.html` 文件完整
- 尝试清除浏览器缓存

### Q2: 请求失败或超时？

**A:**

- 确认后端服务已启动（端口 8091）
- 检查网络连接
- 查看后端日志是否有错误

### Q3: AI回复很慢？

**A:**

- 这是正常现象，LLM推理需要时间
- 简单问题通常较快（1-3秒）
- 复杂问题可能需要10-30秒
- 可以考虑使用本地模型（如Ollama）提升速度

### Q4: 生成的代码有错误？

**A:**

- AI生成的代码仅供参考，需要人工审查
- 可以尝试重新生成或调整需求描述
- 结合具体项目环境进行调整

### Q5: 如何修改界面样式？

**A:**

- 编辑 `ai-assistant.html` 中的 `<style>` 部分
- 主要颜色变量在 CSS 开头定义
- 参考 Element Plus 文档自定义组件样式
